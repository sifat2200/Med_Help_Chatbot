# Project Overview

## Project Name

MedHelp — AI-Powered Medical Chatbot

## Purpose

The project demonstrates how an AI chatbot can combine a language model with retrieval-based information access to answer medical-information questions in a conversational interface.

## Core Technologies

- Python
- Llama 2
- LangChain
- Pinecone
- Flask
- HTML/CSS

## Main Workflow

1. User enters a medical question.
2. The Flask application receives the query.
3. The application performs the configured retrieval workflow.
4. Relevant information is obtained from the vector database.
5. The language model uses the available context to generate a response.
6. The response is returned through the web interface.

## Portfolio Positioning

This project is useful as a demonstration of:

- NLP
- LLM integration
- Retrieval-augmented application design
- Vector databases
- Prompt engineering
- Python/Flask development

## Important Limitation

The project should be described as an educational/research chatbot, not as a clinically validated medical system.
